# StockFlow

Sistema web para controle de estoque e movimentação de materiais.

## Sobre o projeto

O StockFlow é um sistema desenvolvido para auxiliar pequenas empresas, depósitos e almoxarifados no controle de materiais e estoque.

O sistema permitirá centralizar informações sobre os materiais armazenados, registrar entradas e saídas e acompanhar o histórico de movimentações.

## Principais funcionalidades

- Cadastro de usuários;
- Login e autenticação;
- Cadastro de materiais;
- Consulta de materiais em estoque;
- Registro de entrada de materiais;
- Registro de saída de materiais;
- Histórico de movimentações;
- Atualização automática da quantidade disponível.
